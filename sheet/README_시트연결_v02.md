# 업무 현황판_v01 시트 연결 v02 (남은 일정 + 기숙사)

연습장의 「남은 일정」과 「기숙사 현황판」이 시트 「업무 현황판_v01」에 바로 저장되게 하는 방법이에요.
지금 기숙사 현황판(v05)이 쓰는 Apps Script를 **새 버전으로 바꾸기만** 하면 돼요. 주소와 열쇠는 그대로예요.

## 유진님이 할 일 (한 번, 5분)
1. 크롬에서 시트 「업무 현황판_v01」 열기 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고 이 폴더의 `apps_script_v02.gs` 내용을 붙여 넣기 → 💾 저장
3. 위 함수 목록에서 `testRead` → **실행** (시트는 안 바뀌어요. 로그에 기숙사 줄과 남은 일정이 보이면 성공)
4. **배포 → 배포 관리 → ✏️(연필) → 버전: 새 버전 → 배포**  
   주소(…/exec)는 그대로예요. 새 배포를 만들지 마세요.
5. 연습장 → 더보기 → 남은 일정 → **시트 연결**에 그 주소와 EDIT_KEY(스크립트 속성에 넣은 값)를 넣고 저장  
   폰과 PC에서 한 번씩 해요. 기숙사 현황판도 이 연결을 같이 써요.

## 알아 두기
- 열쇠(EDIT_KEY)는 Apps Script **스크립트 속성**에만 있어요. 코드·연습장 저장소에는 없어요. 기기에는 그 기기 브라우저에만 저장돼요.
- 처음 연결하면 「남은일정」 탭이 없으니 앱이 23개로 새로 만들어요.
- 다른 기기에서 먼저 고쳤으면 앱이 「시트 것 받기 / 이 기기 것으로 덮기」를 물어봐요. 말없이 덮어쓰지 않아요.
- 인터넷이 없으면 기기에 저장해 두고, 다음에 열 때 시트로 보내요.
- 고친 기록은 「기숙사_변경내역」 탭에 `연습장(폰)` / `연습장(PC)`로 남아요.
- 전화번호·주민번호처럼 보이는 값은 저장을 막아요.
