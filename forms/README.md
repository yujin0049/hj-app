# 빈 양식 (출석부·서명부 엑셀 저장용)

다른 봇(엑셀봇·공문서 봇)이 준 빈 양식이에요. 값은 모두 가짜(홍길동, 20260000, 000호)고, 앱이 명단을 채울 때 예시 값은 지워요.
어떤 칸에 무엇을 채울지는 `js/attend-forms.js` 의 `tpl` 에 적혀 있어요. 새 양식은 파일을 여기에 넣고 그 배열에 한 덩어리를 더하면 돼요.

| 파일 | 원본 | 용지 |
|---|---|---|
| ojnt_attend.xlsx | 엑셀봇_OJNT어학연수_출석부_빈양식_v01 | A4 가로 |
| ojnt_dorm_sign.xlsx | 엑셀봇_OJNT기숙사_서명부_빈양식_v01 | A4 세로 |
| noncredit_attend.xlsx | 엑셀봇_비교과출석부_빈양식_v01 (그림 연결 경로만 고침) | A4 가로 |
| event_sign.xlsx | 행사참석자_등록부_빈양식 | A4 세로 |
| trip_sign.xlsx | 현장견학_서명부_빈양식 | A4 세로 |
