# 볼트 문서 (Concept)

## 무엇인가요
- 연습장 「더보기 > 볼트 문서」에서 옵시디언 볼트 글을 바로 봐요.
- 폴더 나무, 찾기(제목·본문), 문서 보기, 「마지막 갱신」 시간이 있어요.
- 공부 > 규정 카드의 「원문」에서 같은 볼트 파일이 있으면 「원문 보기」 버튼으로 앱 안에서 열려요.

## 어떤 글이 들어가나요
`tools/vault_folders.json` 에 적힌 곳만 들어가요.
- 00 홈/규칙_총정리.md
- 00 홈/일정총괄.md · 일정총괄.json
- 00 홈/보고서/ 안의 md
- 10 업무/13 글로컬 지출/프로세스/ 안의 md
- 10 업무/산업기사특강/261021_특강_원문대조_v01.md
- 20 규정·지침/ 안의 md

## 자료는 어디서 오나요
1. 볼트(읽기만) → `tools/build_vault_pack.py` 가 팩을 만들어요.
2. 팩은 **저장소 밖** 폴더에만 써요(index.json · search.json · docs/<id>.json · kv_keys.json).
3. 팩을 잠긴 Cloudflare KV `hj-vault` 에 올려요(키 `vault:index` · `vault:search` · `vault:doc:<id>`).
4. 화면은 같은 주소의 잠긴 API 만 불러요: `api/vault/index` · `api/vault/doc?id=` · `api/vault/search?q=`.
- 볼트 글은 GitHub 저장소·공개 연습장에 없어요. 기기에도 저장하지 않아요(서비스 워커도 `/api/` 는 저장 안 함).

## 잠금
- 잠긴 연습장(Cloudflare Access 로그인 + 2차 확인)에서만 보여요.
- 로그인 전(403), 공개 연습장(404), 서버 준비 안 됨(503), 인터넷 없음 → 「잠긴 연습장에서만 보여요」 화면과 「다시 불러오기」.

## 안전
- 주민번호(하이픈 있음·없음·뒤를 *로 가린 꼴)는 팩을 만들 때 항상 「[주민번호 가림]」으로 바꿔요. 숫자는 남기지 않아요.
- 문서 글은 화면에서 글자로만 그려요(HTML 로 읽지 않음). 링크는 http(s) 와 팩 안 문서만.
- `--out` 이 저장소 안이면 스크립트가 멈춰요. `tests/test_vault_guard.py` 가 팩 파일·볼트 문장이 저장소에 들어가면 실패해요.

## 새로 고치는 법
```
python tools/build_vault_pack.py --vault <볼트 뿌리> --out <저장소 밖 폴더>
```
- 끝나면 폴더별 문서 수가 나와요. 그다음 팩을 KV 에 올려요(올리는 일은 잠금 확인 뒤 따로).
- 새 파일은 다시 돌리면 자동으로 들어가요. 범위를 바꾸려면 `tools/vault_folders.json` 만 고쳐요.
