## 순서

### 휴보강 처리
교수 연락 → 공문 → 결재 → 그다음에 앱·달력 고치기

1. 담당 교수가 휴강 사유·보강 날짜를 행정실(카톡)로 알림
2. 보강 날짜는 교수가 수강 학생과 협의
3. 휴보강 계획 내부결재 기안 (휴강 전에 올리는 게 원칙)
4. 결재 끝
5. 결재 뒤에만 출석앱 회차·달력·출석부를 고침
6. 학생 공지 → 보강 실시 → 휴강 시간 = 보강 시간인지 확인

- 교수가 앱에서 직접 바꾸지 않아요. 공문과 앱이 어긋나면 곤란해요.
- 행사로 학생만 빠지는 날: 비정규(원격 포함)·특강은 예정대로 해요. 휴보강 안 해요. (원장 지시)
- 공휴일에 빠진 대면수업은 보강주(16주차)에 보강해요. 원격수업은 공휴일에도 휴강 없어요.
- 교육규정에는 휴강·보강 조항이 없어요. 결석생 보충 조항을 휴보강 근거로 쓰지 않아요.

근거: 운영규정 제15조(수업) · 학사운영 규정 제17조(휴강과 보강) · (비정규면) 운영규정 제14조

### 돈 쓰는 기본 순서 (KORUS)
지출품의 → (계약) → 원인행위 → 검수 → 지출결의 → 지급명령

1. 계획 내부결재
2. (행사·재료면) 제반사항 제공 내부결재
3. 지출품의: 회계관리 > 지출관리 > 지출품의 > 일반지출품의
4. (물품면) 계약등록
5. 원인행위: 지출원인행위 > 원인행위등록
6. 납품 → 검수
7. 지출결의 → 금융기관이체 → 지급확정

- 원인행위 없이는 돈을 못 써요.
- 3천만 원 이하라 계약서를 생략해도 품의·원인행위는 생략하지 않아요.
- 원인행위는 예산 배정 기준. 입금돼야 생기는 돈(외부 재원)은 입금 전엔 지출품의까지만.
- 계획보다 많이 쓰게 되면 지출 전에 승인받아요.
- 학교는 KORUS(코러스)만 써요.

근거: 글로컬 사업비 집행 및 관리지침 · 예산집행기본지침 별표3(수용비 = 계약체결 시)

### 실습재료 구입 (글로컬 DNA+)
학기마다. 수요조사부터 지급까지 담당자가 처리

1. 센터 수요조사 공문 받기
2. 교수별 재료 목록·강의계획서 모으기 (학과 공문 또는 직접)
3. 견적 받기 (500만 원 이상이면 비교견적도)
4. 재료구입 계획 기안·결재
5. 센터에 「재료구입 계획에 따른 제반사항 제공」
6. 지출품의 → 계약(승낙사항 서식28)
7. 원인행위
8. 납품 → 검수 (물품명세서 서식29 · 납품사진 서식36)
9. 지출결의 → 지급

- 견적 유효기간(보통 30일)이 납품 전에 끝나면 다시 받아요.
- 규정 원칙은 원인행위가 납품 전. 남해 글로컬 실무는 납품·검수·세금계산서 뒤 원인행위서에 증빙을 다 붙여 올린 적이 있어요. 건마다 지출 담당에게 확인 필요.
- 재료비는 원인행위 뒤 검수·결의·지급도 담당자가 해요.
- 예산과목: 운영비 – 재료비

근거: 글로컬 사업비 집행 및 관리지침 · 구비서류 양식(부록)

### 기자재 구입
수요조사 → 심의 → 구입계획 → 구입의뢰 → 계약 → 검수 → 등재

1. 센터 기자재 수요조사 공문 받기
2. 학과에서 구매사양서 받기 (품명·모델·물품식별번호·단가·수량, 조달수수료 포함)
3. 기자재심의위원회: 개최 계획 공문(회의 1~3일 전) → 회의 → 결과보고 (등록부·의결서·회의록)
4. 기자재 구입 계획 기안 (추진근거에 심의 계획·결과 공문번호)
5. 구입 의뢰: 글로컬센터 → 행정지원과
6. 계약: 행정지원과
7. 납품 → 검수 (검사·검수서 서식30 · 납품사진 서식36)
8. 물품 등재: 관리번호 스티커, 자산관리시스템에 올리기

- 한 품목이 30만 원을 넘으면 기자재예요.
- 3천만~1억 원 미만은 경남RISE센터, 1억 원 이상은 중앙RISE센터 사전 승인.
- 추정가격 2천만 원 넘으면 입찰.
- 3천만 원 이상은 중요재산 관리, 30일 안에 등록.
- 물품식별번호가 있거나 받을 수 있는 물품만 살 수 있어요.
- 급하면 서면심의로 계획 공문 날 끝낸 선례가 있어요.

근거: 글로컬 사업비 집행 및 관리지침 · 글로컬대학사업단 운영규정 제8조(기자재 심의)

### 특강 운영 (자격증반 등)
계획 → 제반사항 → 강의 전 조회 → 강의 → 강사료 → 결과보고

1. 운영계획 기안·결재
2. 센터에 제반사항 제공
3. 강사에게 성범죄경력조회 동의서(서식12)·행정정보 공동이용 동의서(서식13) 받기 → 강의 전 조회 끝내기 (약 3일 걸림)
4. 강의계획서·일정 공지 (재료는 미리 준비)
5. 강의: 서명부(서식16)·출석부·사진
6. 강사료 서류: 지급신청서(서식14), 개인정보 동의서(서식15), 신분증·통장 사본, 이력서 또는 재직증명서
7. 교육원 지급의뢰 → 센터 원인행위·지출결의
8. 결과보고

- 일회성 특강도 성범죄경력조회를 해요.
- 운영수당이면 사유 생긴 날부터 7일 안에 서류 제출.

근거: 글로컬 사업비 집행 및 관리지침 · 구비서류 양식(부록)

### 초과강사료 (비정규) 매월
실제 시수 확인 → 강의확인서 → 지급 및 지출 의뢰

1. 근거 확인: 비정규 운영계획, 교원별 보수·수당 지급계획, 시간표, 휴보강 계획
2. 그달 실제 시수·초과시수 계산 (4주 묶음)
3. 출석부 → 강의확인서 (통합시스템과 맞는지)
4. 강사료 지급신청서(서식14)
5. 서류 점검: 시수·금액 대조
6. 지급 및 지출 의뢰 공문 (교육원 → 글로컬센터장)
7. 센터 원인행위 → 지출결의 → 지급

- 정규 시수와 보강주 정규 시수는 초과시수에서 빼요.
- 세금·실지급액은 급여 담당이 정한 뒤 적어요. 그 전엔 빈칸.
- 강의확인서나 시트가 통합시스템과 다르면 결의로 안 넘겨요.
- 강사료는 다음 달 5일까지 지급. 정확한 마감은 확인 필요.

근거: 강사료 지급 규정(제49호) 제11조③ · 거창·남해캠퍼스 강사료 특례지침(예규 제137호) 제4조②·제6조

### 국내 출장 → 여비 정산
출장 전에 신청, 다녀와서 2주 안에 정산 서류

1. KORUS 인사 > 복무 > 국내출장 > 국내출장신청 → 상신 (출장 전, 사후 결재 안 됨)
2. 출장 · 영수증 챙기기
3. 출장 결과보고서 (내부결재)
4. 여비정산신청서(서식39) · 영수증 첨부철(서식40) · 자가용이면 운임 내역(별첨2)
5. 4종 묶음 제출: 신청서 → 정산신청서 → 영수증 → 결과보고서
6. 센터가 매달 초 전월분 모아 원인행위 → 지출결의 → 입금

- 제출은 출장 끝난 다음 날부터 2주 안.
- 일비·식비(정액)는 영수증 없어도 돼요. 숙박·교통은 영수증.
- 교육원 직원 출장 결재선은 확인 필요.

근거: 구비서류 양식(부록) · 위임전결 규정(확인 필요)

### 현장견학
품의는 견학 전, 보험은 전날까지

1. 견학 실시계획 (학과장 결재)
2. 필요하면 센터에 제반사항 제공 요청
3. 버스 견적 + 비교견적
4. 일반지출품의 + 수의계약 요청사유서
5. 원인행위
6. 보험은 견학 전날까지 가입
7. 당일: 참가자 명단·서명부·사진
8. 검수(용역 검수조서·사진) → 지출결의
9. 카드 영수증은 쓴 날부터 7일 안 · 결과보고(인솔 출장결과보고)

- 학과가 운영하는 견학은 글로컬 예산이라도 학과가 품의·원인행위·결의를 해요. 글로컬이 직접 운영하면 글로컬이 처리.
- 예산과목: 버스 = 임차료, 보험 = 공공요금 및 제세

근거: 글로컬 사업비 집행 및 관리지침 · 규칙 목록 R11~R14

### 행사 (다과·식사·현수막)
개최계획 → 제반사항 → 쓰기 → 7일 안 영수증 → 결과보고

1. 행사 개최계획 결재 (안전대책 포함)
2. 제반사항 제공 내부결재 (관련란에 개최계획 문서번호)
3. 지출품의 → 원인행위
4. 법인카드로 쓰기
5. 검수: 현수막·인쇄는 물품명세서(서식29)·사진
6. 카드 영수증은 쓴 날부터 7일 안에 제출 → 지출결의
7. 결과보고

- 현수막: 카드명세서, 결과보고, 검수사진, 납품, 견적, 품의, 계획
- 다과: 카드명세서, 사진, 등록부, 결과보고, 품의, 계획
- 식사: 카드명세서, 등록부, 결과보고, 품의, 계획
- 회의·행사 식대 1인 20,000원, 다과 1인 7,000원까지

근거: 글로컬 사업비 집행 및 관리지침 Ⅳ.2.자

### 제반사항 제공 (내부결재)
계획 결재 뒤, 돈 쓰기 전에 올리는 문서

1. 관련란: 계획 공문 번호
2. 무엇에 얼마 쓰는지 표 (산출근거 곱셈 = 금액)
3. 예산과목 · 붙임
4. 결재: 센터장까지

- 1,000만 원 이상 쓰는 글로컬 문서와 계획 문서는 부총장까지.
- 결재가 9일 걸린 선례가 있어요. 마감에서 거꾸로 세고 1주 여유.

근거: 학교 내부 기준 (규칙 목록 R18·R19)

### 공문 받았을 때 (이송·경유)
우리 일인지 먼저 보고, 아니면 맞는 부서로

1. 받은 공문 제목·붙임·기한 확인
2. 우리 일이 아니면 → 맞는 부서로 이송
3. 다른 기관을 거쳐 보내야 하면 → 경유 (예: 상급 기관을 거쳐 담당 과로)
4. 회신이 필요하면 「관련」에 받은 공문 번호를 적고 제출 공문 작성

- 외부 공문이 대학운영실 등에서 먼저 접수된 뒤 학과·교육원으로 이송되는 일이 많아요.
- 경유 공문의 수신란 쓰는 법은 확인 필요.

근거: 행정업무 운영 편람 (확인 필요)

### 주간업무보고
교수별 3칸 → 취합 → 업무회의

2. 취합본 만들기
3. 업무보고회의자료: 일자·장소·대상·내용
4. 남은 일정 체크리스트 갱신

### 연수생 기숙사 입사
입사 신청 공문 + 신청서 묶음

1. 생활관 입사 신청 공문 (수신: 학생생활관장) + 입사 신청서
2. 기숙사 장단기 사용신청서
3. 서약서 서명본
4. 실거주 확인서
5. 입사 서류 점검

- 기숙사비 = 200,000원 × 학생 수 × 4개월. 강사·직원은 넣지 않아요.
- 4인 1실 · 통제 시간 23:30~05:00

근거: 학생생활관 규정 제5조①·제31조 · 운영지침(예규 제174호)

### 사물함 관리
장부 → 공고 → 배정 → 학기말 반납

1. 장부: 번호·위치·열쇠 수·상태
2. 배정 기준: 열쇠 2개짜리부터 (1개 학생, 1개 행정실)
3. 사용 신청 공고 → 1명 1개, 신청 순서대로
4. 열쇠 수령·반납 확인대장 서명
5. 신고 없는 잠긴 사물함: 재공고 → 교직원 2명 이상 입회해 열기 → 사진·목록 → 행정실 보관
6. 학기말 반납 공고

### 시험 시간표·추가시험
대학운영실 협조 공문에 맞춰 제출

1. 대학운영실 협조 공문 받기
2. 시험일시·고사장·감독 교수 시간표 작성 → 담당 교수·학과장 승인
3. 교무학사팀에 제출 공문 (바뀌면 「변경」으로 다시)
4. 추가시험: 학생 응시원 + 증빙 → 학과장 승인 → 공문

- 추가시험 마감은 정규 학과 과목만 해당. 교육원 과목은 해당 없음.

### 국토부 입과·결과 보고

## 용어

### 휴보강
휴강(수업을 쉼) + 보강(나중에 채움). 시수는 그대로 맞춰요.

### 공결 · 출석인정
정해진 사유(학교 행사·현장교육 등)로 빠진 걸 결석으로 치지 않는 것. 기준은 출결 지침 — 확인 필요

### 비정규 (교육과정)
국토부 전문교육기관 시간을 채우려고 교육원이 따로 여는 과목. 졸업학점엔 안 들어가요. (운영규정 제14·27조)

### 정규 (교육과정)
학과 교육과정 과목. 학사 시스템에서 관리

### 원격 (수업)
온라인 수업. 정해진 기간(2주) 안에 들으면 돼요. 공휴일에도 휴강 없음

### 초과강사료
교원이 정해진 책임시수를 넘겨 가르친 시간에 주는 강사료 (매월, 4주 묶음)

### 수의계약
입찰 없이 골라서 맺는 계약. 2천만 원 이하 물품은 1인 견적도 가능

### 비교견적
다른 업체 견적을 하나 더 받아 값을 비교. 글로컬은 500만 원 이상이면 필수

### 지출품의
돈 쓰겠다고 먼저 허락받는 문서 (KORUS 일반지출품의서)

### 원인행위
예산을 쓰기로 확정하는 단계 (계약 맺을 때). 이것 없이는 지출 못 해요

### 지출결의 · 지급명령
검수 끝난 뒤 실제로 돈을 내보내기로 하는 단계 → 돈이 나감

### 검수
물건·용역이 계약대로 왔는지 확인하고 조서·사진을 남기는 것 (강사료는 강의확인)

### 제반사항 제공
계획 결재 뒤, 행사·사업에 드는 돈(식비·재료 등)을 쓰겠다고 올리는 내부결재

### 승낙사항
작은 물품 계약 때 계약서 대신 쓰는 서식 (서식28)

### 물품분류번호 · 식별번호
조달청이 물품마다 매기는 번호. 구매사양서에 적고, 이 번호가 있어야 글로컬로 살 수 있어요

### 등재 (물품)
산 기자재를 자산 시스템에 올리고 관리번호를 붙이는 것

### 이송
우리 소관이 아닌 공문을 맞는 부서로 넘기는 것

### 경유
공문을 다른 기관(보통 상급 기관)을 거쳐 보내는 것

### 내부결재
밖으로 보내지 않고 안에서 결재만 받는 문서. 발신명의 없음

### KORUS (코러스)
학교 회계·인사·전자결재 시스템. 품의·원인행위·결의·출장신청 모두 여기서

### e나라도움
국고보조금 시스템. 글로컬 집행 등록·정산을 여기서

### 글로컬 (대학사업)
정부 재정지원 사업. 남해캠퍼스 글로컬대학사업센터가 돈을 관리해요

### RISE
지역혁신중심 대학지원체계. 글로컬 돈도 RISE 지침을 따라요 (경남RISE센터·중앙RISE센터)

### DNA+
Defense·Nuclear·Aerospace + 첨단 분야 인재양성 과제. 남해캠퍼스는 방산·항공(MRO) 쪽

### OJNT
해외 취업연수 과정(싱가포르 항공정비). 재원은 한국산업인력공단 — 글로컬 아님

### ATIMS (항공교육훈련포털)
국토부 보고 시스템. 입과·결과를 입력하면 보고한 것으로 봐요

### 보강주
학기 16주차. 공휴일 등으로 빠진 대면수업을 채우는 주

### MRO
항공기 정비·수리·분해점검 (Maintenance, Repair, Overhaul)

### T번호
업무 건마다 붙인 번호 (예: T020). 현황판·폴더에서 같은 번호로 찾아요
